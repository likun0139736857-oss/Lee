# Lee-study · 个人学习看板构建与动态维护

## 使命

把用户的学习资料库蒸馏为「点开即学、自动算进度、可动态更新」的数字化学习看板：md 体系（数据源）+ 单文件 HTML 交互站点（学习入口）。封装从语料探查、RIA++ 蒸馏、看板组织、站点生成到增量维护的完整流水线。

## 输入与输出

- **输入**：任意学习资料（PDF/EPUB/DOCX/PPTX/PNG 扫描件/视频文稿/纯文本/文件夹）
- **输出**：
  1. 学习看板 md 体系：00 选课指南（总纲+进度总表）+ 01-08 阶段目录（README + 自包含学习模块 + 待精读清单）
  2. 单文件交互站点 `index.html`（离线自包含、零外部依赖）
  3. 更新日志 `更新日志.md`

## 工作流

### 1. 探查语料

- 完整读取全部输入，识别格式与可读性；大文件分块阅读，PDF 可用页截屏/OCR 兜底
- 无法读取的文件（扫描图片版无文本层/损坏文件）如实标注到待精读清单，严禁编造内容

### 2. 蒸馏为学习模块

- 按仓颉 RIA++ 六段式蒸馏：**R** 原文要点（≤150 字+来源标注）/ **I** 解读（重写骨架）/ **A1** 案例（语料真实案例）/ **A2** 应用情境 / **E** 执行步骤（1-2-3 可操作）/ **B** 边界（不适用场景/误区）
- 每模块同步生成：自测题（选择/判断/简答+折叠答案）、闪卡（≥4 张）、知识图卡五类（概念/框架/案例/清单/边界）、四问引导（听想变用+专家视角）、一页纸总结、推荐书单（1-3 本）
- 模板见 `assets/module-template.md`；结构与格式规范见 `references/structure.md`

### 3. 组织看板

- 00 选课指南：README 总纲（使用说明/阶段总览表/学时预算/进度方法）+ 学习进度总表
- 01-08 阶段目录：每阶段 README 标注学习目标/前置依赖/建议学时/前后衔接/模块清单/进度表
- 模块文件自包含：点开即学，无需跳转原始文件

### 4. 生成站点

- 用 Python 构建脚本把全部 md 转成单文件 `index.html`（技术规范见 `references/site-spec.md`）
- 内容全嵌入、hash 路由、四态进度%、localStorage 持久化、自测判分、闪卡翻转

### 5. 验证

- `node --check` 校验 JS；真实浏览器实测（渲染/导航/状态切换/进度公式/刷新持久化）
- 进度公式手算核对：阶段% = 等效完成数 ÷ 模块数；全局% = Σ(阶段等效完成 × 阶段学时) ÷ Σ(阶段模块数 × 阶段学时)
- 验证通过后交付 `index.html`

### 6. 动态更新（增量维护）

- 触发：用户放入新文件/文件夹、或按周定时巡检
- 按 `references/update.md` 执行增量流程：扫描 → 蒸馏 → 归入阶段 → 重建 → 日志
- 硬性边界：学习记录（localStorage 学习状态/四问/测评/待重思/复盘卡/书单标记）一律不更新到知识库

## 质量标准

- 模块 RIA++ 六段式完整；自测题/闪卡/图卡/四问/一页纸/书单齐备
- 推荐书单必须真实存在：拿不准的书先搜索核验（书名+作者+出版社），严禁编造
- 站点零外部依赖、离线可开、进度%自动计算、数据持久化
- 原始语料与既有 md 体系零改动（只增不改）
- 内容全部来自语料实际读取，不凭记忆蒸馏
