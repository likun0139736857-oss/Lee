# 学习看板结构规范

## 目录结构

```
学习看板/
├── 00 选课指南/
│   ├── README.md            # 总纲：使用说明/8阶段总览(主题·学时·前置·衔接)/进度方法/语料索引
│   └── 学习进度总表.md       # 跨阶段模块总跟踪 + 学习日志
├── 01 认知筑基-思维模型与学习方法/
│   ├── README.md            # 学习目标/前置/学时/衔接/框架/模块清单+进度表
│   └── 01-0X 模块.md         # 自包含学习模块
├── 02 科学素养-科技前沿与理性思维/    （同结构，可含待精读清单.md）
├── 03 商业洞察-新商学与组织管理/
├── 04 沟通实战-表达与协作能力/
├── 05 自我成长-心理学与健康管理/
├── 06 人文视野-阅读历史与批判思维/
├── 07 工具方法-品控体系与职场工具箱/
├── 08 年度复盘-报告年鉴与知识沉淀/
├── 学习复盘卡/               # 复盘卡归档文件夹（+使用说明）
├── 更新日志.md               # 每次增量更新记录
├── index.html               # 交互站点（构建产物）
└── build_html.py            # 构建脚本（md→单文件站点）
```

## 阶段命名与划分建议

按学习进阶分层，8 阶段示例（可按语料主题调整）：
01 认知筑基 → 02 科学素养 → 03 商业洞察 → 04 沟通实战 → 05 自我成长 → 06 人文视野 → 07 工具方法 → 08 年度复盘

## 阶段 README 要素

- 学习目标（一段话，可考核）
- 前置依赖（依赖哪个阶段，无则写"无"）
- 建议学时（如 15-30h）
- 与前后阶段的衔接关系
- 知识框架（层级化结构梳理）
- 模块清单表 + 进度表（# / 模块 / 状态 / 进度%）
- 精读语料清单（来源文件）

## 模块 md 格式要点

- 头部：来源标注 + 学习状态行（⬜未开始 0% / 🔄学习中 50% / ✅已完成 100% / ⭐已掌握 100%）
- 正文 R/I/A1/A2/E/B 六段
- 自测题：`<details><summary>查看答案</summary>**答案：…**。解析：…</details>` 折叠
- 闪卡：`<details><summary>术语</summary>解释</details>` 翻卡式
- Q/A 速查表（Markdown 表格）
- 推荐阅读书单（1-3 本，真实可核验）
- 完整模板见 `assets/module-template.md`

## 待精读清单

无法读取/未精读的素材单列：相对路径 + 原因（扫描件/损坏/时间未及）+ 优先级，供后续深读回填；不得编造内容。
