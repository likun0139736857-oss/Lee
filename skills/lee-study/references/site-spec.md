# HTML 站点生成规范

## 总体要求

- 单文件自包含：CSS/JS/内容全内联，零外部依赖、无 CDN、离线可开（file:// 直开）
- 中文界面；蓝/绿/橙中性配色（避免大面积紫/靛蓝）；桌面为主、窄屏可读
- 构建脚本（build_html.py）可重跑：读取全部 md → 解析结构化内容 → 生成 DATA → 嵌入模板 → 单文件输出

## 路由与视图

- hash 路由：#home（总览）/ #stage/<sid> / #module/<sid>/<mid>，以及聚合视图（my-books、rethink-all 等）
- 总览页：全局进度条 + 阶段卡片（模块数/学时/进度%）+ 待重思总览 + 我的书单 + 全库一页纸速览

## 进度体系

- 四态：⬜未开始=0 / 🔄学习中=0.5 / ✅已完成=1 / ⭐已掌握=1
- 阶段% = Σ模块等效完成 ÷ 模块总数 × 100%
- 全局% = Σ(阶段等效完成 × 阶段学时) ÷ Σ(阶段模块数 × 阶段学时) × 100%（学时加权）
- 点击切换状态即重算；localStorage 持久化，刷新不丢

## localStorage keys

| key | 用途 |
|---|---|
| dedaoboard_v1 | 模块状态 `{modules:{mid:0-3}}` |
| dedaoboard_log_v1 | 学习日志（时间戳+操作） |
| dedaoboard_favcards_v1 | 收藏知识图卡 |
| dedaoboard_siwen_v1 | 四问笔记（含 expert/expert2/dualMode 字段） |
| dedaoboard_quiz_v1 | 测评记录与历史 |
| dedaoboard_onepage_v1 | 一页纸已回顾标记 |
| dedaoboard_rethink_v1 | 待重思队列 |
| dedaoboard_review_v1 | 复盘卡标记 |
| dedaoboard_books_v1 | 书单想读/已读标记 |

新增 key 必须与既有 key 兼容，不得破坏旧数据格式。

## 模块视图功能

- 四步步骤条：知识图卡 → 四问引导 → 学后测评 → 一页纸（完成点亮）
- Tab：知识图卡 / 正文精读(RIA++) / 四问引导 / 学后测评 / 一页纸 / 闪卡 / 推荐书单
- 知识图卡：五类徽章（概念/框架/案例/清单/边界），可收藏
- 四问引导：听·想·变·用 + 专家视角选择器（11 位连锁/定位专家，标注「参考名单·非权威排名」）+ 双视角对照 + 待重思错题
- 学后测评：逐题即时判分、错题回顾、测评历史、≥80% 达标建议
- 一页纸总结：一句话核心 + 关键要点 + 速记卡 + 行动建议，支持复制/打印/下载
- 闪卡：3D 翻转
- 推荐书单：书名 + 作者 + 出版社 + 一句话理由 + 想读/已读标记
- 学习复盘卡：一页纸 + 四问 + 测评合并，复制 Markdown / 下载 .md

## 构建与验证

1. Python 脚本读 md → 解析（模块/自测题/闪卡/书单）→ DATA JSON → HTML 模板 → index.html
2. `node --check` 校验 JS 语法
3. 真实浏览器实测：渲染/导航/状态切换/进度公式手算核对/刷新持久化/既有功能回归
4. 验证通过后交付；交付前清理**测试环境/本轮测试写入**的数据回 0% 干净状态。用户实际 localStorage 学习记录（各 dedaoboard_* key：学习状态/四问/测评/待重思/复盘卡/书单标记）一律不得读取、清除或覆盖——清理仅限本轮浏览器实测产生的测试数据
