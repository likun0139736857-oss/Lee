# 个人决策库｜公开脱敏视图

更新：2026-10-15。完整统一个人决策库仍由用户指定的本地固定文档维护，本页仅为公开生成摘要，不单独形成第二套决策记录。

## 已明确认可的模型

| 编号 | 模型 | 调用与边界 |
|---|---|---|
| INF-01 | 互惠 | 识别帮助或让步对合作意愿的影响；感谢不替代对具体请求的判断 |
| INF-02 | 承诺和一致 | 查看自主承诺与后续行动；条件变化可以重新评估，会场认同不等于履行 |
| INF-03 | 社会认同 | 查看相似他人的行为参照；多个转述不是多个独立证据 |
| INF-04 | 喜好 | 关系、好感与方案质量分别核查；熟悉不保证正确 |
| INF-05 | 权威 | 核对专业相关性、证据与利益；身份不保证当前建议成立 |
| INF-06 | 稀缺 | 核实真实限制、替代方案及实用价值；难得不等于值得 |

以上均为Lee明确认可、可调用的经验性模型，不是已在本人业务中全部验证的第一性定律。理解他人、指导互动、自我审查三种用途并存。

## 认可与证据状态

作者方法不自动成为Lee立场；明确认可不自动成为实践结果；AI新规范和新组合先作候选；个人实际决定只记明确选择，不把老师建议或草稿写成决定。即时反应、后续行动、结果及可归因结果分开记录。

CAND-01“让关键贡献得到可信背书”、CAND-02“先创造具体价值，同时保持选择独立”仍待逐条确认，不作为已确认的个人准则。具体私人案例、第三人身份、合作待遇、目标数字、完整决策经过及原始证据不在公开视图中发布。

需要当前案例、本人决定或验证状态时，从授权的本地固定源核对。公开版本不可冒充完整个人决策库或当事人的全部立场。
